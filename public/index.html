가격을 비교하기 전에

원화와 엔화는 같은 후보를 각각 조회한 표시 요금이에요. 환율로 계산한 값이나 결제 통화 보장은 아니에요. 경유편은 현지 도착 시간이 제공되지 않아 실제 체류 박수를 예약 화면에서 확인해야 해요. 수하물·경유 횟수·출도착 시각은 확인되지 않았어요.

기록 기준과 업데이트 방식

월간 API의 제한된 후보만 비교해요. 과거 브리핑에서 복원한 기록은 최저가 요약만 포함하며, 새 기록은 반환된 후보 전체를 보관해요. 통화 선택은 동일한 원화 최저가 일정의 표시 통화를 바꾸며, 엔화 최저가를 새로 선정하지 않아요.

새로운 JSON 기록이 GitHub에 커밋되면 Netlify가 다시 빌드해요. 이 정적 페이지 자체는 항공권을 수집하거나 예약하지 않아요.
